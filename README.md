# Robert's Control-M Collection

A collection of various scripts, queries, plugins and utilities I've written and released into the public over my years of working with BMC Software's Control-M.
## Requirements
Control-M v20 or above (may work with lower versions, not guaranteeing it)

## Contents
* plugins - Application Integrator plugins
* useful-scripts - Useful utility scripts that run on both the EM and Server
* sql - Database queries

## Contributing

Unless otherwise noted, most of these items are from Robert Stinnett (myself).  However, I believe in the community spirit, so feel free to contribute and give appropriate credit!

Pull requests are welcome.
